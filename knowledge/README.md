# Kunskapsbank

Ämnesmaterial tillkommer i fas 2. Ingen modul är ännu `verified`.

## Föreslagen modulordning
01-kooperation, 02-medlemskap-och-styrning, 03-virkesaffaren, 04-industriell-foradling, 05-insatskapital, 06-insatsemission, 07-vinstdelning, 08-aterinvesteringar, 09-risker-och-alternativ, 10-langsiktigt-medlemsvarde.

Varje modul ska ha titel, `status: draft|verified`, lärandemål, begrepp, självständigt faktainnehåll, datum för tidskänsliga uppgifter och länkar till övningar. `verified` används först efter sakgranskning. Källor används i utvecklings- och faktagranskningsarbetet; reproduktion av skyddade texter undviks.
