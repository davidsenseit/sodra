# Begrepp – insatskapital och vinstdelning
status: draft

**Inbetalt insatskapital:** Kapital som medlemmen har betalat in till föreningen enligt dess villkor.

**Emitterat insatskapital:** Kapital som tilldelats medlemmens individuella insatskonto genom insatsemission.

**Insatsemission:** Omföring inom föreningens eget kapital som tilldelar medlemmar emitterat insatskapital enligt beslutade grunder.

**Överinsats:** Frivilligt inbetalt insatskapital utöver den obligatoriska insatsen inom gällande gränser.

**Utdelning på virkesleveranser:** Vinstdelning baserad på berättigade leveranser enligt beslut för aktuellt år.

**Kontant utdelning på insatskapital:** Utbetalning beräknad enligt beslutad grund för insatskapital.

**Vinstdelningspolicy:** Långsiktig princip för hur resultat kan fördelas; ingen garanterad avkastning.

**Likviditet:** Möjlighet att använda tillgängliga betalningsmedel; skiljer sig från nominellt insatskapital.
