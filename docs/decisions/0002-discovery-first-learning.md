# ADR 0002 – Discovery-first learning across ten modules

status: proposed
date: 2026-11-05

## Context
The first course prototype made open-ended response and mastery demonstration mandatory before moving on. This creates a high interaction cost for casual learners who primarily want to understand Södra's economics. It also risks turning a guided learning journey into an exam.

## Decision
Retain ten ordered knowledge modules, fact status, glossary and quality controls. Replace the mandatory answer loop with a narrative discovery loop: scenario, meaningful choice, consequence, grounded explanation, optional low-stakes transfer, and continuation. Add one corresponding discovery file per knowledge module. Short A/B text input is the universal fallback. A learner can say 'fortsätt'; explanations and sequence continue even without an answer. Do not confuse coverage with demonstrated mastery.

## Alternatives
Mandatory written answers: strong evidence of reasoning but high friction. Exclusive multiple-choice tests: low friction but prone to guessing and quiz fatigue. Unstructured chat: flexible but inconsistent content coverage and factual controls. Full interactive web app: expressive but violates URL-first AI-neutral scope.

## Consequences
Benefits: lower interaction overhead, more contextual economic reasoning, consistent portable instruction. Risks: less measurable mastery, artificial branching, hallucinated details, reduced recall if too passive. Mitigate using planned transfer questions, grounded scenario files, tracked core insights and portable regression tests. Empirical claims remain unverified until user testing.
