# Övningsbank och facit för AI-assistenten

status: draft

Befintliga kortsvars-, räkne- och resonemangsövningar är en **intern diagnostisk bank**, inte en lista med obligatoriska uppgifter som deltagaren ska skriva ut svar på. `discovery/` är standardvägen för elevupplevelsen.

AI-assistenten får omvandla ett frågemål till ett kort A/B-val, ett scenario, en förutsägelse eller ett genomarbetat exempel om sakinnebörden, antaganden och facit bevaras. Använd ursprungliga mål-ID:n och kontrollera att förklaringarna inte förenklar bort nödvändiga förbehåll. Frivilliga fördjupningssvar i fritext är tillåtna.

Ingen övning ska användas för att blockera progression efter felaktigt eller uteblivet svar. En rätt gissning är inte bevis på självständig mastery. Uppgifter och facit förblir draft tills faktagranskade.

Se [pedagogy/ASSESSMENT.md](../pedagogy/ASSESSMENT.md) och [discovery/README.md](../discovery/README.md).
